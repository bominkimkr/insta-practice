# 인스타 연습장 (insta-practice)

소상공인 인스타그램 첫 화면을 직접 바꿔 보는 연습용 가상 화면. 파일 하나(`index.html`)로 동작하고, 외부 접속·서버·로그인이 없습니다. 사진은 전부 연습용 그림(실제 매장 사진 아님)입니다.

## 깃허브 페이지에 올리기 (수행확인서 앱과 같은 방법)

1. github.com → **New repository** → 이름 `insta-practice` → Public → Create
2. **Add file → Upload files** → 이 폴더의 `index.html` 올리고 Commit
3. **Settings → Pages** → Branch `main` / `(root)` → Save
4. 1~2분 뒤 `https://bominkimkr.github.io/insta-practice/` 에서 열림

강의 슬라이드(`_강의/1019_인스타그램_실습_강의.html`) 표지와 13장에 이 주소가 들어가 있습니다. 저장소 이름을 바꾸면 슬라이드의 주소도 바꿔야 합니다.

## 쓰는 법 (20분 실습)

1. 사례 고르기 — 벌통곱창(전) · 쏘핏PT(전) · 내 매장(빈 계정). 초록 테두리 버튼은 컨설팅 세팅안(후) — 먼저 직접 바꿔 보고 나서 열기
2. 「프로필 편집」 → 이름 칸 「상호 | 동네 업종」 · 소개 4~5줄 · 링크 1번 네이버 예약 · 맨 아래 「동네 말 / 업종 말」 입력(점검용)
3. 하이라이트 동그라미 → 제목 두 글자로 4~5개
4. 게시물 → 「프로필에 고정」 3개 · 틀린 정보 게시물 삭제 · 사진 바꾸기(폰 사진 가능)
5. 오른쪽(폰에선 「점검 보기」) 10점 확인 → 「전·후 이미지로 저장」 → 「패들릿에 올리기」(https://padlet.com/bominkim1/1019-s024m8dxrfllki8q7139)

입력 내용은 그 기기 브라우저에만 저장됩니다(localStorage). 「처음으로」를 누르면 지워집니다.
